What O does differently

  • Everything is logged, in a hash chainevery tool call, policy decision and engine step; Verify chain says ✓ or ✗ at #n
  • No mouse or keyboard takeoverworks inside your own tabs and on accessibility nodes; your cursor is yours
  • Cached replay with zero model callsan identical request replays its saved script; a saved procedure replays step by step
  • High-risk steps run in a sandboxa throwaway Docker container or E2B box, destroyed after; the path sandbox otherwise, and it says so
  • Local-first, with your own Claude logina loopback API proxy over claude -p; no API key; nothing listens off-machine
  • Declarative UI, never raw HTMLplans and progress are checked frames mapped onto the panel's own components

Claims as stated in the O README; demos recorded against the real engine, action log and API proxy.
